## Struktur Folder

```text
pertemuan-XX/
├── tugas-pendahuluan.md
├── kegiatan-praktikum/
│   ├── README.md
│   └── screenshots/
│       └── .gitkeep
└── tugas-mandiri/
    ├── backend/
    │   └── README.md
    └── frontend/
        ├── web/
        │   └── README.md
        └── mobile/
            └── README.md
```

- `tugas-pendahuluan.md` berisi identitas serta bagian jawaban yang dilengkapi ketika pertemuan berlangsung.
- Setiap `README.md` berisi judul, tujuan, cara menjalankan, hasil, dan lokasi bukti.
- `screenshots/.gitkeep` adalah berkas kosong bernama tepat `.gitkeep` (bukan `.gitkeep.txt`) agar folder tetap terlacak git sebelum bukti tersedia.
