## Struktur Folder Setiap Pertemuan

```text
pertemuan-XX/
├── tugas-pendahuluan.md
├── kegiatan-praktikum/
│   ├── README.md
│   └── screenshots/
│       └── .gitkeep
└── tugas-mandiri/
    ├── backend/
    │   └── README.md
    └── frontend/
        ├── web/
        │   └── README.md
        └── mobile/
            └── README.md
```

- `tugas-pendahuluan.md` berisi identitas serta bagian jawaban yang dilengkapi ketika pertemuan berlangsung.
- Setiap `README.md` berisi judul, tujuan, cara menjalankan, hasil, dan lokasi bukti.
- `screenshots/.gitkeep` adalah berkas kosong bernama tepat `.gitkeep` (bukan `.gitkeep.txt`) agar folder tetap terlacak git sebelum bukti tersedia.
- Kerangka disalin dari pertemuan-01 ke pertemuan-02 s.d. pertemuan-16 sebelum jawaban diisi, agar jawaban satu pertemuan tidak terbawa ke pertemuan lain.
- Jawaban yang sudah ada (contoh: `pertemuan-02/tugas-mandiri/backend/tugas-mandiri-1-http-method.md` beserta screenshot PUT/DELETE) dipertahankan dan tidak ditimpa oleh kerangka.
